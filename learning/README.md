# Learning

Student work lives in this tree. Each folder name is a ticket slug
(`pa-knn`, `ra-types`, `lr-jetson`). Programming assignments subclass the
previous class through [`load_assignment.py`](load_assignment.py). Readings
go in `answers.md`. Datasets and generation notes:
[`resources/data/README.md`](resources/data/README.md).

This repository lives in your mentor’s GitHub organization. You have Write
access. Do not push to `main`; open a pull request. First ticket:
[git](../issues/00-git.md).
