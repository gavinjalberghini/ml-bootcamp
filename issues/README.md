# Tickets

Each `NN-slug.md` file is the body of one GitHub issue. Mentors open them
on a student repo with `scripts/create_issues.sh` (called from
`deploy_student.sh`). Work happens under `learning/<slug>/`.

Do them in filename order. The slug is the ID used for branches, commit
scopes, and Task names.
