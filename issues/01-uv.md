# [uv] Python and uv

You need: git done (this repo cloned, `learning/README.md` on a branch).

You will: install Python and uv, then run a script whose dependencies are
declared **in the file**. Every later programming assignment uses that same
pattern. You will not create a project virtualenv and `pip install` into it.

## Steps

1. Install **Python 3.10 or newer** if `python3 --version` is missing or older.
   - Windows: [python.org downloads](https://www.python.org/downloads/) or `winget install Python.Python.3.12`
   - macOS: `brew install python` or the python.org installer
   - Linux: your package manager (`sudo apt install python3` on Debian/Ubuntu)
2. Install **uv**: follow [uv installation](https://docs.astral.sh/uv/getting-started/installation/). Then open a new terminal and run `uv --version`.
3. Open `learning/uv/hello.py`. It already has a [PEP 723](https://peps.python.org/pep-0723/) header:

   ```python
   # /// script
   # requires-python = ">=3.10"
   # dependencies = []
   # ///
   ```

   That header is how uv knows which Python and which packages the file needs.
   Empty `dependencies` means stdlib only.
4. From the repo root run:

   ```bash
   uv run learning/uv/hello.py
   ```

   You should see `hello from uv` and a Python version of 3.10+. uv will
   download a Python if the system one is too old. There is no `venv` for you
   to activate.
5. Write `learning/uv/notes.md` with: `uv --version`, the Python version
   `hello.py` printed, and one sentence in your own words on what the
   `# /// script` block is for.
6. On a branch named `uv/hello`, commit `learning/uv/notes.md` and open a
   pull request:

   ```bash
   git checkout -b uv/hello
   git add learning/uv/notes.md
   git commit -m "docs(uv): record python and uv versions"
   git push -u origin uv/hello
   gh pr create
   ```

## How later assignments use this

Each `learning/<slug>/…py` file has its own `# /// script` block. `uv run`
reads **that file**, not `pyproject.toml`. If A imports B, A must re-list
any third-party package it still calls. Do not `pip install` globally.
The next ticket installs Task so `task knn` wraps the same `uv run`.

## Stretch goal (optional)

Skip if you want. Put `hello.py` `dependencies` back to `[]` afterward.

**Challenge:** Add a tiny third-party package to `hello.py`'s header, `uv
run` it, write what happened in `learning/uv/stretch.md`, then restore
`dependencies = []`.

## Acceptance criteria

- `uv run learning/uv/hello.py` prints a 3.10+ version without activating a venv.
- `learning/uv/notes.md` exists and answers the prompts in step 5.
- A pull request includes that file. The branch is `uv/…` and the commit
  subject matches `type(scope): description`.
- Stretch is optional. Skipping it does not block taskfile.
