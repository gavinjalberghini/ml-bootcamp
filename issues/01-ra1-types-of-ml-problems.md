# [Reading Assignment 1] Types of Machine Learning Problems

Description: Before moving on to more advanced modelling techniques, it is important to establish a strong understanding of machine learning classification. For this task, I would like you both to read about the fundamentals of classification in ML, including how classifiers are trained and evaluated.

Additionally, focus on the differences between binary classification, multi-class classification, and multi-label classification. Pay particular attention to how predictions are structured and evaluated in each case, and consider how these differences might impact implementation decisions in your own algorithms (including kNN).

As you read, think about the following:
- How does classification differ from regression?
- What distinguishes multi-class from multi-label problems?
- How do evaluation metrics change depending on the classification type?
- What challenges arise as the number of classes or labels increases?
