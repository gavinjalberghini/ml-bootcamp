# [Programming Assignment 0] Own This Repository

This copy of the template is yours. Later assignments, reviews, and conversation
all happen in this repo. The goal of PA0 is to prove that loop works: clone,
branch, commit, push, and open a pull request into *your* default branch.

Git is the version-control tool; GitHub is the host. You need both.

**Do not use GAI to do the git operations for you.** Read the references if
the commands are new.

## What to do

1. Clone **this** repository (the one created for you from the template), not
   the upstream template.
2. Create a branch. A name like `pa0-setup` is enough; it does not need to be
   your personal name.
3. Edit `learning/README.md`. Fill in your name, a short background (coursework,
   languages, anything you already know about ML), and what you want to learn
   from this mentorship.
4. Commit the file and push the branch.
5. Open a pull request from that branch into `main` (or `master`) so your
   mentor can review it.

You will use the same pattern for later assignments: one branch, one focused
diff, one pull request.

## Acceptance criteria

- `learning/README.md` exists on a pushed branch and contains your name,
  background, and learning goals.
- A pull request is open against this repository's default branch.
- You can clone, pull, commit, push, and open a PR without help.
